您的 GitHub 账号用户名
用于存放客户档案数据的仓库（需为公开仓库）
默认为 main 分支
JSON 数据文件在仓库中的路径
需要 repo 权限的 Personal Access Token
点击此处创建 Token
每隔多少秒自动从云端拉取最新数据（10-300）
使用说明：
1. 在 GitHub 创建一个公开仓库
2. 点击上方链接创建 Token（勾选 repo 权限）
3. 填写信息后点击"保存并连接"
4. 将此 HTML 文件分享给同事，他们填写相同的配置即可
5. 所有人的修改会自动同步到云端，其他人定时拉取
注意：Token 仅保存在本地浏览器中，不会上传
